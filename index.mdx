This documentation describes the inspected main package version **9.3.0** (pnpm **12.10.1**). It is built from the source tree available at inspection time and is not an independently verified published release. Where commands, settings, or hardware behavior are noted without explicit confirmation, they are marked as unconfirmed. No hardware tests were run to produce this documentation.

LIVI is an open-source **Apple CarPlay and Android Auto head unit**. It runs on Linux (desktops and embedded ARM platforms such as Raspberry Pi) and macOS. The project provides a native, zero-copy GStreamer video pipeline with hardware-accelerated decoding, low-latency audio, multitouch and D-Pad navigation, and support for very small embedded and OEM displays.

## Supported platforms and hardware

LIVI targets the following platforms per the README and marketing site. These claims are from the source; they have not been independently tested for this documentation.

- **Linux desktops** (Debian, Ubuntu, Fedora, and other distributions)
- **Raspberry Pi OS Trixie** (Debian 13) on Raspberry Pi 4, Pi 5, CM4, and CM5
- **Other arm64 and x86_64 Linux devices** capable of running Electron (distributed as an AppImage)
- **macOS** on Apple Silicon and Intel

> **Important:** OpenGL ES 3.x is required. The Pi 3 and earlier use VideoCore IV (OpenGL ES 2.0 only) and are unsupported.

## What LIVI does

- **Native Apple CarPlay** (wired and wireless) on Linux and macOS
- **Native Android Auto** (wired on all platforms, wireless on Linux)
- **Multi-session** with live switching between connected phones
- **Hardware-accelerated H.264/H.265** video decoding (and VP9/AV1 where the platform decoder supports it)
- **Instrument cluster video stream** support
- **Multi-display** routing with freely assignable Dash and Aux windows
- **Touchscreen, multi-touch, D-Pad, and hard-key input**
- **Display calibration** (gamma, contrast, RGB channels) applied by the compositor
- **GPS** via NMEA-0183 serial receiver with automatic timezone and time setting
- **Telemetry dashboard** with CLI tooling for local testing
