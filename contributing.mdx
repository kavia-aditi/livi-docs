LIVI combines TypeScript, Rust, and GStreamer. Use the [Project Structure](/project-structure) to find the relevant code and [Build, Test, and Lint](/build-test) to prepare a change against the inspected **9.3.0** package.

## Prepare a Change

<Steps>
  <Step title="Identify the Current Owner">
    Start with [Architecture](/architecture). Phone sessions live in the native core; Electron manages the application interface and its integration with that core.
  </Step>
  <Step title="Run Relevant Checks">
    The package provides `pnpm run typecheck`, `pnpm run test`, and `pnpm run lint:check`. `pnpm run lint` and `pnpm run format` write changes to files. Review those changes before sharing them.
  </Step>
  <Step title="Describe What You Verified">
    Include reproduction steps, affected platform, and checks you actually ran. Distinguish unit-test results from hardware testing. Installer changes can alter host services and boot configuration.
  </Step>
</Steps>

<Note>
  A formal submission policy or contributor agreement was not verified. Do not treat this page as a maintainer-approved pull-request policy. No builds, tests, or hardware checks were run while drafting these guides.
</Note>
